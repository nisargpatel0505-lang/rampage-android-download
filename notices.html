The character adaptations combine meshes and materials, convert palette colours to vertex colours, normalize the forward axis, select and rename animation clips, and add an original simple pistol. Map layouts, collision setup and selected scenery were composed for RAMPAGE in Blender. The asset provenance record identifies the exact downloaded source files and their hashes. These specific releases carry CC0; this is not a blanket licence claim for every asset on a creator’s website.

The original synthesized sound effects and City Afterglow music are available under the original audio notice / CC0 dedication. Blender and the glTF exporter/validator are development tools; their executables are not game assets.

Native Android runtime

The game was built with Unity 6000.6.6f1, revision d20c9ac777da, using its Android IL2CPP player. The unchanged Unity Android player third-party notice bundle preserves the vendor's component attributions and licence texts. It is a vendor-wide inventory; optional components can be removed from an individual game by build settings and code stripping.

The APK also contains LLVM's native C++ runtime, libc++_shared.so, from Android NDK r27c (27.2.12479018). The libc++ and libc++abi licence sections are retained unchanged from that NDK's notice file, including the LLVM exception and legacy licence texts. Source details and exact hashes are in the notice manifest.
